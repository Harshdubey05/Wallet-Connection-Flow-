# Web3 Wallet Connection Flow (UI/UX Showcase)

An ultra-premium, futuristic Web3 wallet connection experience inspired by Apple, Stripe, and high-end crypto applications. This project focuses entirely on delivering a frictionless, secure, and visually stunning user interface for connecting wallets.

## ✨ Key Features

- **Ultra-Premium Aesthetics:** Deep charcoal dark mode, subtle radial gradients, and dynamic noise textures.
- **Glassmorphism Design:** Frosted glass cards with `backdrop-blur` and layered semi-transparent borders.
- **Smooth Micro-interactions:** Fluid hover states, subtle button scaling, glow bursts, and custom keyframe animations.
- **Trust-First UX:** Prominent security badges, clear copy, and intuitive visual cues.
- **Complete Connection Flow:**
  - Landing / Connect Entry
  - Wallet Selection Modal (MetaMask, WalletConnect, Coinbase)
  - Animated Connecting State
  - Signature Request UI
  - Success (Glow burst) & Error (Shake animation) states
- **Mobile-Responsive:** fully adaptable to any screen size.

## 🛠️ Tech Stack

- **React 18**
- **Vite**
- **Tailwind CSS v4** (with custom variant configurations and `@tailwindcss/vite`)
- **Lucide React** (for crisp, premium iconography)

## 🚀 Running Locally

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **View the app:**
   Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🎨 Design Philosophy

This project serves as a showcase for high-quality frontend design in the Web3 space. It demonstrates that connecting a wallet doesn't have to be a confusing or unpolished experience. By utilizing modern CSS features and thoughtful animations, we build immediate trust with the user before they even sign their first transaction.
